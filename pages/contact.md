# Contact

Vous souhaitez former vos managers, accompagner une prise de poste, structurer vos OKR, renforcer la QVCT ou travailler la cohesion d'une equipe ? Decrivez simplement votre contexte et le besoin prioritaire.

## Pour quels sujets me contacter ?

- Formation management motivationnel.
- Coaching de manager ou prise de poste.
- Accompagnement OKR et pilotage de la performance.
- QVCT, securite psychologique et prevention RPS.
- Seminaire de cohesion ou engagement strategique.
- Management hybride, teletravail et outils collaboratifs.

## Informations utiles a partager

Pour preparer un premier echange, vous pouvez indiquer :

- le type d'organisation et la taille de l'equipe concernee ;
- le probleme principal observe ;
- le public vise : managers, RH, CODIR, equipe projet ;
- le format souhaite : formation, coaching, atelier, diagnostic, conference ;
- l'echeance ou le calendrier envisage.

## Message de contact

Pour le moment, le point de contact public peut etre votre profil GitHub :

**CTA :** Envoyez-moi un message pour decrire votre projet et organiser un premier echange.
